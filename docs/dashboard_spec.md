# Sample layout contract

Synthetic Data — For Demonstration Only

This is a reusable test fixture, not stakeholder requirements. Name: SyntheticActivityFixture. Canvas: 1280×720. Overview uses a title/reporting period header, four KPI cards (Revenue, Active Users, Conversion Rate, ARPU), a native line trend, native segment comparison, a native detail table, and disclosure footer. Use Date and Segment slicers when building the report. Detailed analysis may add cohort/segmentation pages once metric contracts are supplied. Templates/layouts/overview.json supplies nonoverlapping panel coordinates; reserve space within panels for titles/axes/slicers.

No report or visual has been created or rendered by this setup. User designs and background assets take precedence over sample styling.
