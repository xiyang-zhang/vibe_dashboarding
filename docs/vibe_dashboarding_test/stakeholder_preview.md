# Stakeholder preview

Synthetic Data — For Demonstration Only

The local PBIP contains Performance, Engagement and Cohort Retention pages using the supplied navy and orange template. Six-month synthetic results include $38,037.79 revenue, 1,136 distinct active users, 18,000 sessions and 2,014 conversions. These are demonstration data, not business performance.

The heatmap shows calendar-month activity retention for signup cohorts. The denominator includes inactive enrolled users. Future months are absent, and age zero reflects actual activity rather than an imposed 100%. Distinct users and ratios must be recomputed when combining periods, segments or cohorts.
